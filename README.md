# Azure Chat 2

כלי לצוות לשליפה ועדכון של Work Items ב-Azure DevOps (GOI-Finance / Portfolio Merkava).
אתר סטטי בלבד, בלי שרת. הדפדפן של המשתמש מדבר ישירות עם Azure DevOps עם ה-PAT של המשתמש, כך שכל אחד רואה ומעדכן רק לפי ההרשאות שלו.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | המסך |
| `css/app.css` | עיצוב |
| `js/core.js` | שליפה, טבלה, תמונות, Excel, העתקה (מבוסס על Azure Chat 1.3) |
| `js/meta.js` | שדות, ערכים מותרים ומבנה הטופס מ-Azure DevOps |
| `js/team.js` | הגדרות הצוות, התבנית, בדיקת התבנית, שמירה ל-GitHub |
| `js/team-settings.js` | מסך "הגדרות צוות" |
| `js/edit.js` | עדכון: חלון עריכה מהטבלה, פקודות בצ'אט, עדכון מרובה, תגובות |
| `demo/meta.json` | עותק מייצג של מבנה השדות (למצב הדגמה ולבדיקות) |
| `team-config.json` | הגדרות הצוות: שדות חובה ותבנית Description. נערך ממסך "הגדרות צוות" |
| `vercel.json` | כותרות אבטחה ומטמון לפרסום ב-Vercel |

## פרסום

האתר: https://azure-chat-lake.vercel.app

כל push ל-`main` מתפרסם אוטומטית ב-Vercel.

## הגדרות צוות

מסך "הגדרות צוות" שומר את `team-config.json` ישירות ל-GitHub (דורש GitHub token עם הרשאת Contents: Read and write ל-repo הזה בלבד). אחרי השמירה Vercel מפרסם מחדש, ותוך כדקה כל הצוות מקבל את ההגדרות.

## עדכון פריטים

- **מהטבלה:** לחיצה על תא או על ✎ פותחת חלון עריכה.
- **בצ'אט:** `112074 State Resolved` · `110047 112074 Iteration 4.2` · `112074 שייך לאני` · `112074 Priority=2; Tags +SAP` · `112074 תגובה: טקסט`
- כל שמירה מוצגת קודם לאישור (לפני ← אחרי).
- לפני כל שמירה נבדקים שדות החובה (של Azure ושל הצוות) והתבנית של Feature. שמירה לא תעבור אם חסר משהו.
- השמירה כוללת בדיקת גרסה: אם מישהו אחר עדכן את הפריט בינתיים, השמירה נעצרת ולא דורסת.
- נדרש PAT עם הרשאת **Work Items: Read & Write**.

## יצירת פריטים

- **+ פריט חדש** למעלה, **+ תת-פריט** בחלון העריכה, או בצ'אט: `חדש Task תחת 110047: כותרת` · `צור באג: כותרת` · `חדש Feature: כותרת; Leading Squad Meteor`
- פקודה בצ'אט פותחת טופס ממולא. היצירה עצמה רק אחרי לחיצה על "יצירה ב-Azure".
- תת-פריט מקבל Area ו-Iteration מהאב. בלי אב: מהפריט האחרון שנוצר במחשב הזה.
- Feature חדש נפתח עם התבנית. שדות החובה (Azure + צוות) והכותרות שמסומנות כחובה נבדקים לפני היצירה.
- סוג אב לא רגיל (למשל Task תחת Feature) מסומן באזהרה, אבל לא נחסם.
